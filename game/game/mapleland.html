메이플랜드 원격 임대

메이플랜드(Mapleland)는 넥슨의 메이플스토리 월드 플랫폼에서 즐기는 RPG 월드로, 옛날 메이플스토리를 기반으로 재구성한 2D 횡스크롤 게임입니다. 메이플스토리 월드 클라이언트로 PC와 모바일에서 실행하며, 최대 플레이어 300명으로 소개됩니다.
플랫폼 클라이언트의 공식 사양이 높지 않아 원격PC로 이어가기 부담이 적고, 원격PC에 클라이언트를 설치해 두면 휴대폰으로 상태만 확인하면서 접속을 유지할 수 있습니다. 메이플스토리 본편이나 클래식 월드와는 서비스가 다르다는 점만 주의해 주세요.

메이플랜드, 원격PC로 시작하는 4단계

  1. 용도 알려주기
    카카오톡으로 메이플랜드에서 몇 계정을 운영할지 알려주세요.
  2. 관리자 추천
    메이플스토리 월드 클라이언트 사양과 계정 수에 맞는 옵션과 대수를 추천해 드립니다.
  3. 클라이언트 설치·로그인
    원격PC에 메이플스토리 월드 클라이언트를 설치하고 본인 넥슨 계정으로 로그인해 메이플랜드를 실행합니다.
  4. 원격 접속
    원격 접속 창을 닫아도 게임은 계속 실행되고, 휴대폰 원격 앱으로 상태만 확인하면 됩니다.

메이플랜드 원격 임대 자주 묻는 질문

메이플랜드는 어떤 게임인가요?
넥슨의 메이플스토리 월드 플랫폼에서 즐기는 RPG 월드로, 옛날 메이플스토리를 기반으로 재구성한 2D 횡스크롤 게임입니다. PC와 모바일에서 실행할 수 있고 최대 플레이어는 300명으로 소개됩니다.
메이플스토리 월드 클라이언트는 어떻게 설치하나요?
넥슨 메이플스토리 월드 사이트의 다운로드 페이지에서 PC 클라이언트를 설치하고 넥슨 계정으로 로그인한 뒤 메이플랜드를 실행합니다. 설치와 로그인은 고객님이 직접 하시고, 궁금한 점은 카카오톡으로 문의해 주세요.
PC 사양은 어느 정도 필요한가요?
메이플스토리 월드 클라이언트 기준 최소 사양은 Windows 10 64bit, Core i3, 메모리 4GB, GeForce 8600 GT급이고 권장은 Windows 11 64bit, Core i5, 메모리 8GB, GTX 650급입니다. 월드마다 사양이 다를 수 있어 메이플랜드의 정확한 기준은 상담 시 함께 확인합니다.
메이플랜드는 자동 사냥이 되나요?
공식 안내에서 자동 사냥 기능은 확인되지 않았습니다. 규정은 공식 공지를 기준으로 안내해 드리며, 외부 자동화 프로그램은 지원하지 않습니다.
여러 계정을 한 PC에서 돌릴 수 있나요?
다중 접속 허용 여부와 제한은 공식 안내에서 확인되지 않았습니다. 허용 범위를 확인한 뒤 그 안에서만 안내해 드리고, 계정 수를 알려주시면 맞는 옵션을 먼저 상담해 드립니다.
메이플스토리 클래식 월드와 같은 게임인가요?
아니요. 이름이 비슷하지만 메이플랜드는 메이플스토리 월드 플랫폼의 월드이고, 메이플스토리 본편이나 클래식 월드와는 서비스가 다릅니다. 원하시는 게임을 정확히 알려주시면 맞는 안내를 드립니다. 메이플스토리 안내 보기 →
