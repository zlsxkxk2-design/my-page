뮤 온라인 원격 임대

뮤 온라인은 웹젠이 서비스하는 PC MMORPG로, 780레벨 이상 육성 구간까지 이어지는 성장형 게임입니다. 2026년 9월에는 흑기사·마검사·레이지파이터·슬레이어 4개 클래스의 전투 밸런스가 개선되고, 빠른 육성을 돕는 스피드 서버가 열렸습니다.
공식 PC 사양이 낮아(웹젠 글로벌 공식 사이트 기준 권장 RAM 2GB) 원격PC로 돌리기 부담이 적고, 육성에 시간이 드는 게임이라 24시간 켜진 원격PC에 클라이언트를 설치해 두면 휴대폰으로 상태만 확인하며 이어갈 수 있습니다.

뮤 온라인을 원격PC로 즐길 때 알아둘 점

스피드 서버

빠른 캐릭터 육성을 지원하는 스피드 서버가 2026년 9월에 열렸고, 스피드 서버에서 키운 캐릭터는 본 서버로 무상 이전할 수 있습니다. 사전 등록 이용자에게는 블러드엔젤 주무기 상자와 방어구 풀세트 같은 기간제 장비가 지급됐습니다.

신규 서버 '듀크'

정액제 이용자는 10월 중 개설 예정으로 안내된 신규 서버 '듀크'로도 캐릭터를 이전할 수 있다고 소개됐습니다. 서버를 옮길 때는 육성 레벨 구간에 따른 보상이 제공됩니다.

클래스 4종 밸런스 개선

흑기사·마검사·레이지파이터·슬레이어의 공격력과 스킬 공격력 등 전투 위력이 상향됐고, 슬레이어에는 전용 신규 옵션과 스킬 강화 트리 변경이 있습니다.

780레벨 이상 스피드 서버 플러스

780레벨 이상 육성한 캐릭터는 '스피드 서버 플러스'로 1,200레벨까지 추가 육성을 지원하는 강화 재료를 받을 수 있습니다. 육성 구간이 긴 만큼 접속을 오래 유지하는 환경이 편합니다.

공식 PC 사양이 낮아요

웹젠 글로벌 공식 사이트 기준 최소는 Atom 1.6GHz·RAM 1GB·내장 그래픽이고, 권장은 Core 2GHz·RAM 2GB·GeForce 8600급입니다. 원격임대 전 옵션이 이 기준을 넘습니다.

신작 '뮤 테오스' 소식

웹젠은 2027년 상반기 출시를 목표로 개발 중인 뮤 IP 신작 MMORPG '뮤 테오스'의 게임명과 BI를 공개했습니다. 뮤 온라인과는 별도 게임입니다.

뮤 온라인 원격 임대 자주 묻는 질문

뮤 온라인은 어떤 게임인가요?
웹젠이 서비스하는 PC MMORPG로, 클래스별 육성과 스피드 서버·서버 이전 같은 성장 시스템이 이어지는 게임입니다. 2026년 9월 흑기사·마검사·레이지파이터·슬레이어의 전투 밸런스가 개선되고 스피드 서버가 열렸습니다.
스피드 서버는 무엇인가요?
강화된 클래스로 신규 캐릭터를 빠르게 육성할 수 있는 서버입니다. 스피드 서버에서 키운 캐릭터는 본 서버로 무상 이전할 수 있고, 780레벨 이상 캐릭터는 스피드 서버 플러스로 1,200레벨까지 추가 육성 지원 강화 재료를 받을 수 있습니다.
PC 사양은 어느 정도 필요한가요?
웹젠 글로벌 공식 사이트 기준 최소는 Windows 7 이상, Atom 1.6GHz, RAM 1GB, 내장 그래픽이고 권장은 Core 2GHz, RAM 2GB, GeForce 8600급입니다. 한국 서비스는 기준이 다를 수 있어 한국 공식 공지를 함께 확인하며, 원격임대 전 옵션이 이 수준을 넘습니다.
뮤 온라인은 자동 사냥이 되나요?
공식 안내에서 자동 사냥(오토) 기능은 이번에 확인되지 않았습니다. 규정은 공식 공지를 기준으로 안내해 드리며, 외부 자동화 프로그램은 지원하지 않습니다.
여러 클라이언트를 한 PC에서 켤 수 있나요?
다중 클라이언트 허용 여부와 제한은 공식 안내에서 확인되지 않았습니다. 허용 범위를 확인한 뒤 그 안에서만 안내해 드리고, 계정 수를 알려주시면 맞는 옵션을 먼저 상담해 드립니다.
원격 접속을 끊어도 게임이 계속 켜져 있나요?
네. 원격 접속 창만 닫히고 원격PC와 실행 중인 게임은 계속 켜져 있습니다. 휴대폰 원격 앱으로 들어가 육성 상태만 확인하시면 됩니다.
뮤 테오스와 같은 게임인가요?
아니요. 뮤 테오스는 웹젠이 2027년 상반기 출시를 목표로 개발 중인 뮤 IP 신작이고, 뮤 온라인과는 별도 게임입니다. 출시가 가까워지면 별도로 안내해 드리겠습니다.
