아스달 연대기 원격 임대 자주 묻는 질문

아스달 연대기를 원격PC에서 어떻게 실행하나요?
원격PC에 넷마블 PC 런처로 아스달 연대기 PC 버전을 설치해 실행합니다. 로그인은 고객님 계정으로 직접 하시면 됩니다.
세력전 시간에만 직접 조작할 수 있나요?
네. 평소에는 자동사냥을 켜 두고, 필요한 시간에 휴대폰·PC로 원격 접속해 직접 조작하시면 됩니다.
최소 RAM이 16GB인데 괜찮나요?
모든 옵션이 RAM 24GB 이상(5700G는 32GB)이라 RAM 기준은 충족합니다.
